这个 GitHub 项目，正在解决 AI 编程最容易被忽略的问题：上下文浪费。

它叫 Context Mode，今天我们只看一个结论：AI 写代码时，真正贵的，不只是模型，而是不断塞进上下文窗口的原始数据。

一个网页快照，可能就是几十 KB。几十个 Issue、一次日志读取，很快就会把上下文填满。上下文一旦被压缩，AI 可能忘记刚才改过哪些文件，也忘记任务进行到哪一步。

Context Mode 的思路，是把原始工具输出放进沙箱和本地索引里，不直接全部塞给模型；需要的时候，再通过搜索取回相关内容。项目 README 给出的示例是，三百一十五 KB 的原始数据，可以压缩到大约五点四 KB，减少百分之九十八的上下文占用。

它还会把文件修改、Git 操作、报错和用户决策记录到 SQLite，再通过全文搜索找回相关事件。简单说，就是让 AI 少看废话，多看真正相关的内容。

不过要注意，这不是装上就能让 AI 变聪明的魔法。它更适合已经在用 Claude Code、Cursor 或其他 Agent 工具的开发者，而且项目许可证是 Elastic License 2.0，商业使用前一定要先看清楚限制。

我的结论是：值得收藏，可以尝鲜，但先不要把它当成生产环境的万能优化器。想看我继续实测哪个 GitHub 项目，评论区留下仓库名。
